# Butgetbath
Lead-generation website for Budget Bath Solutions (bathroom remodeling and tile in Kane, Kendall, DuPage and DeKalb counties, Illinois).

- Static, SEO-focused site generated by `build.js` (Bootstrap 5.3), with homeowner help, community Q&A, service-area and legal pages.
- Free customer accounts: email verification, photo and video uploads (photos up to 8 MB, MP4/MOV/WebM videos up to 100 MB, 10 files per request) with per-file comments, and a threaded request (ticket) system with categories, priorities, a progress stepper, upcoming appointments, a staff inbox (search, sort, filters), internal notes, email notifications and email replies. Email is sent with Resend.
- Landing page built for booking: an above-the-fold estimate form (preferred day and time), FAQ with schema markup and local business schema.

```
npm install
npm start    # builds and serves on http://localhost:3000
npm test
```

Configuration, Resend setup and deployment notes are in [DEPLOYMENT.md](DEPLOYMENT.md). Copy `.env.example` to `.env` and never commit it.

## Appointments

Staff (`ADMIN_EMAILS`) schedule, reschedule and cancel appointments from a customer's request page. Each change emails the customer a confirmation with an `.ics` invite (`METHOD:REQUEST`/`CANCEL`), plus "Add to Google Calendar" and Apple/Outlook links. Customers see upcoming appointments on their dashboard and can cancel (staff are emailed).

- **iCalendar**: per-appointment download at `/api/appointments/:id/ics`, and a private subscription feed for staff (shown on the staff requests page) that works with Apple Calendar, Outlook and Google Calendar "From URL".
- **Google Calendar sync** (optional): set `GOOGLE_CALENDAR_ID` and `GOOGLE_SERVICE_ACCOUNT_JSON` (see `.env.example`). Without them, only the links, `.ics` files and feed are used.

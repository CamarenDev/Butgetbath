# Butgetbath
Lead-generation website for Budget Bath Solutions (bathroom remodeling and tile in Kane, Kendall, DuPage and DeKalb counties, Illinois).

- Static, SEO-focused site generated by `build.js` (Bootstrap 5.3), with homeowner help, community Q&A, service-area and legal pages.
- Free customer accounts: email verification, photo uploads with per-photo comments, and a threaded request (ticket) system with statuses, staff inbox, internal notes, email notifications and email replies. Email is sent with Resend.

```
npm install
npm start    # builds and serves on http://localhost:3000
npm test
```

Configuration, Resend setup and deployment notes are in [DEPLOYMENT.md](DEPLOYMENT.md). Copy `.env.example` to `.env` and never commit it.
